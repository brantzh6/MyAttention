# Control Plane Scheduling Protocol

This document describes the intended scheduling for all control-plane
automation loops in the MyAttention project.

## Loop Summary

| Component | Cadence | Model | Script | Output |
|-----------|---------|-------|--------|--------|
| **Deterministic reconciler** | Every 15 minutes | No model | `scripts/ops/control_plane_reconciler.ps1` | `ops/state/observed_state.json` |
| **Runtime lightweight probe** | Every 10 minutes | No model | `scripts/ops/runtime_probe.ps1` | `ops/runtime/latest.json` |
| **PM compact snapshot** | Every 15 minutes (via reconciler) | No model | `scripts/ops/write_pm_control_snapshot.ps1` | `ops/state/pm_control_state.json` |
| **ike-pm LLM coordinator** | Every 4 hours + escalated events | LLM (bailian/qwen3.6-plus) | OpenClaw ike-pm agent | `ops/pm-runs/latest.json`, triggers |
| **ike-operator** | Event-driven (controller packet dispatch) | LLM (bailian/qwen3.6-plus) | OpenClaw ike-operator agent | Task result artifacts |

## Detailed Behavior

### 1. Deterministic Reconciler (15 min, no model)

- **Script:** `scripts/ops/control_plane_reconciler.ps1`
- **Purpose:** Close the control-plane loop after detached Codex runs.
- **Responsibilities:**
  - Reconcile bridge run states through the lifecycle:
    `queued -> dispatched -> running -> completed | failed | timeout -> consumed`
  - Detect expired leases, dead PIDs, and missing result artifacts.
  - Clean stale bridge lock files only when proven safe (lease expired/gone +
    lock age > 30 min, or PID dead + lock age > 5 min).
  - Compare observed state (from probe) against accepted state
    (`ops/state/current_state.json`); flag `controller_attention_required`
    with evidence when they conflict.
  - Generate a compact PM snapshot via `scripts/ops/write_pm_control_snapshot.ps1`
    that routine PM cycles read first.
  - **Never** mutate controller-owned accepted state automatically.
- **Output:** `ops/state/observed_state.json` (machine-readable),
  `ops/state/pm_control_state.json` (compact PM snapshot)
- **Encoding:** All JSON writes use UTF-8 without BOM. Shared helper
  `scripts/ops/ops_encoding_helpers.ps1` (`Write-JsonUtf8NoBom`) is used
  by the reconciler; delegated state writers must validate no leading
  `EF BB BF`.

### 2. Runtime Lightweight Probe (10 min, no model)

- **Script:** `scripts/ops/runtime_probe.ps1`
- **Purpose:** Observe runtime reachability without mutating anything.
- **Probes:** Web (3000), API (8000), Redis (6379), Postgres (5432).
- **Web probe behavior:** Probes root `/` and `/control` separately.
  Web status is `healthy` only when root is HTTP 200 **and** `/control`
  returns HTTP 200 containing **both** markers `file_derived` and `PM Watch Digest`.
  Root reachable but `/control` unreachable or missing markers → `degraded`.
  Root unreachable → `unreachable`.
- **Other probes:** TCP connection tests + HTTP endpoint checks. Redis sends PING.
  Postgres checks Windows service status + TCP reachability.
- **Output:** `ops/runtime/latest.json` (machine-readable)
- **Constraint:** Observation only. No restart, no config change.
- **Encoding:** JSON writes use UTF-8 without BOM.

### 3. ike-pm LLM Coordinator (4h + escalated events)

- **Trigger:** OpenClaw cron job `9cbc70a5-0118-40aa-aa24-8379d0c5113d`
- **Purpose:** Project coordination, progress audit, blocker escalation,
  gate auditing.
- **Read behavior:** Read `ops/state/pm_control_state.json` (compact
  snapshot) FIRST for every routine cycle. Deep-read
  `ops/state/current_state.json` only when the compact snapshot is missing,
  invalid, stale (older than 15 minutes past the reconciler tick),
  contradictory, or has `decision_hint.escalation_needed = true`.
- **Behavior:** Judges progress against gates, writes run digest to
  `ops/pm-runs/latest.json`, triggers when controller coordination is needed.
- **Bridge:** Invokes Codex controller via
  `scripts/ops/openclaw_codex_bridge.py` when coordination is needed.
- **PM digest `reason`:** Must describe the active `next_action`, not a
  superseded blocker copied from history.

### 4. ike-operator (Event-driven)

- **Trigger:** Controller packet dispatch only (not time-based).
- **Purpose:** Runtime operation, readiness verification, repair tasks.
- **Behavior:** Runs bounded repair/verification packets authorized by
  the controller. Writes result artifacts.
- **Scope:** Runtime operation, not source code edits (unless explicitly
  authorized in the packet).

## Scheduling Rationale

- The reconciler and probe are cheap (no LLM cost) and run frequently to
  catch state transitions quickly.
- The compact PM snapshot is generated by the reconciler at no extra cost,
  giving the PM coordinator a bounded read surface for routine cycles.
- The PM coordinator uses an LLM and runs every 4 hours to reduce token
  pressure; it fires on escalated events outside the cadence.
- The operator is event-driven and only activates when a controller packet
  is dispatched, preventing unnecessary runtime churn.

## Integration Notes

- The reconciler reads `ops/runtime/latest.json` from the probe for
  state comparison. Run the probe before the reconciler for best results.
- The reconciler also generates `ops/state/pm_control_state.json` (compact
  PM snapshot) after writing observed state.
- The PM coordinator should read `pm_control_state.json` FIRST for every
  routine cycle. Deep-read `ops/state/current_state.json` only when the
  compact snapshot is missing, invalid, stale, contradictory, or has
  `decision_hint.escalation_needed = true`.
- `dispatched` is not a terminal bridge state; the reconciler detects
  completion evidence and reclassifies to `completed`, `failed`, or
  `timeout` accordingly.
